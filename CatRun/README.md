# CatRun

## 1. 概要・コンセプト
Unity + ML-Agents (PPO) を用いた、プレイヤーが報酬と罰とマウス操作でAIを調教・誘導するゲーム

## 2. 現状の動作
![キャットランのイメージ動画](<sample-image/CatRun.gif>)

## 3. 技術スタック（Tech Stack）
- Unity 6
- Unity ML-Agents Toolkit (PPO)
- Python / PyTorch

## 4. 現在の進捗と技術的課題

【実装済み】
- カーソルとの相対位置
- カーソルの移動速度
- クリック(ワンクリック、ホールド)
- 直近のクリック記憶
- 直近のジャンプ傾向
- 直近の横移動傾向

【直面している課題と試行錯誤】
- **高度な行動（ジャンプ・停止など）の学習:**「ジャンプ」や「停止」などのプレイヤーの意図・指示を学習させ、ゲーム性を成立させることが現在の目標。
