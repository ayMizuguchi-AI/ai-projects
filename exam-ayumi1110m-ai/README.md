# HIBARI 技術試験 ver2.0

本リポジトリには2つの独立した技術試験が含まれています。それぞれの課題に対してデータ処理パイプラインを構築してください。

---

## 試験一覧

| # | 課題 | ディレクトリ | 概要 |
|---|------|-------------|------|
| 1 | 異常検知 | [`pipeline-challenge/`](pipeline-challenge/) | Eコマースデータから異常を検知するパイプライン |
| 2 | レコメンデーション | [`recommendation-challenge/`](recommendation-challenge/) | ユーザーごとの商品推薦を生成するパイプライン |

---

## 進め方

各課題はそれぞれのディレクトリ内で完結しています。各ディレクトリのREADMEを参照してください。

```bash
# 異常検知
cd pipeline-challenge
cat README.md

# レコメンデーション
cd recommendation-challenge
cat README.md
```

---

## 共通要件

| 項目 | 要件 |
|------|------|
| **実行方法** | 各課題ディレクトリ内で `docker compose up` で実行 |
| **使用言語** | 自由（Python, Go, Rust, Node.js 等） |
| **制限時間** | サンプルデータに対して 10 分以内 |
| **リソース上限** | メモリ 4GB、CPU 2コア |
| **ネットワーク** | 採点時はネットワーク無効 |

---

## 採点

各課題は **600点満点** で自動採点されます。提出（push）すると自動でビルド・実行の成否が確認され、採点が管理者側で実行されます。結果は別途通知されます。
