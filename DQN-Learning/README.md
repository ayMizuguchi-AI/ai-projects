# DQN-Learning

ブラウザ上でAI（DQN: Deep Q-Network）学習でブロック崩しを学習していく過程を、リアルタイムで観察、調整できるWebアプリケーションです。

## 機能・特徴
- **学習シミュレーション**
  - エージェント（バー）が失敗を繰り返しながら、徐々にボールを打ち返せるようになるプロセスを可視化。
- **ニューロンモニター機能**
  - TensorFlow.jsを使い、中間層や出力層のニューロンがどう活性化しているか（Q値の推移など）をリアルタイムに描写。
- **ステータス調整**
  - 探索率（ε-greedy法）、割引率（γ）、学習率（Learning Rate）をスライダーで自由に変更可能。
  - 「ボールを打ち返した時の報酬」「落下した時のペナルティ」などの報酬設計もブラウザ上でリアルタイムに変更・実験できます。
- **学習倍速**
  - 等倍（1x）から最大100倍速（100x）までスピードを変更し、高速に学習を進めることができます。
- **モデルのインポート / エクスポート**
  - 学習させたAIのモデルデータをJSON/バイナリ形式でローカルに保存したり、過去のモデルを読み込んで再開したりできます。
- **DQN学習解説**
  - 強化学習やDQNの仕組みを説明した解説スライド機能を搭載。

## 動作環境・使用技術
- フロントエンド: HTML5, CSS3, JavaScript (Vanilla JS)
- 機械学習ライブラリ: TensorFlow.js
- **推奨ブラウザ**: **Microsoft Edge**
  - ※現在レスポンシブ非対応のため、Edge以外のブラウザではデザインが崩れる場合があります。恐れ入りますがEdgeでの閲覧・実行をお願いいたします。

## 使い方
1. このリポジトリをクローン、またはZIPファイルでダウンロードします。
2. 解凍したフォルダ内にある `index.html` を、推奨ブラウザ（Edge）で直接開きます。
3. 画面上の「スタート」ボタンを押すと、AIの学習シミュレーションが始まります。
4. 左側のコントロールパネルや下側のスピードパネルから、各種パラメータ、報酬設定や学習速度をリアルタイムに変更して実験できます。画面の詳しい説明はメニューの「遊ばせ方」から見ることができます。

## こだわったポイント
- **AI内部の視覚化（ニューロンモニター）**
  - 本来は見ることのできないAIの内部を視覚的に理解できるようにモニター画面を実装しました。
- **噛み砕いた解説ページの作成**
  - AIの魅力を伝えるため、自分が学んだDQN学習の仕組みを初心者でも分かりやすいように言葉を選び、スライド形式で解説するページを作成しました。
- **世界観に合わせたUIデザイン**
  - 「AIの学習シミュレーション」というテーマにマッチするよう、サイバー感や近未来感のあるUIデザインを意識して構築しました。

## ディレクトリ構成
主要なファイル構成は以下の通りです。

```text
├── index.html            # メイン画面（ゲーム＆モニター）
├── game-js/              # ゲーム・AI関連のロジック
│   ├── main.js           # 画面全体のイベント・初期化処理
│   ├── game.js           # ゲームの物理演算・描画ロジック
│   └── ai.js             # DQNのネットワーク定義・学習ロジック
├── game-css/             # 各画面パーツのスタイルシート
└── etc/                  # その他リソース
    ├── how-to-play.html  # 遊び方画面
    ├── explanation.html  # DQN学習解説画面
    └── explanation.js    # 解説画面のテキスト描写ロジック
```
