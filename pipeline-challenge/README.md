# AI-Powered E-Commerce Anomaly Detection Pipeline

## 概要
ECサイトにおける不正注文や不正アクセスを検知するための、ハイブリッド型（ルールベース ✕ 機械学習）の異常検知パイプラインです。
大量の注文データ（CSV）およびアクセスログ（JSONL）をパースし、不審な行動パターンを自動的に検出・スコアリングしてレポート（JSON）を出力します。

※セキュリティおよび機密保持（NDA）の観点から、検証用データセットおよび一部のシェルスクリプトは非公開としています。システムの中核ロジックは `main.py` をご参照ください。

## システムの特徴と設計思想

### 1. ハイブリッド検知アーキテクチャ
統計的なアプローチ（ルールベース）と、機械学習による多角的な判定を組み合わせた設計にしています。
* **統計ルール層:** 注文金額の Z-score（対数変化率ベース）、10分間の高頻度連打注文、特定IPからの異常アクセス（1時間100回以上）などの外れ値を高速にフィルタリング。
* **機械学習層 (RandomForestClassifier):** 14種類の特徴量（深夜早朝購入率、e-wallet利用率、成約率、POST/GET比率など）を抽出し、ルールだけではすり抜ける「複合的な怪しい挙動」を確率（`predict_proba`）で再判定。

### 2. こだわったポイント（特徴量エンジニアリング）
単なるデータ分析に留まらず、不正組織の行動パターンを想定したドメイン特有の特徴量を実装しました。
* `user_post_get_ratio`: 機械的なスクリプティング（Bot行動）を見抜くための、アクセス型（GET）とアクション型（POST）の比率
* `user_avg_order_interval`: 人間では不可能なミリ秒単位の連続購入を検知する平均注文間隔
* `user_product_diversity`: クレジットカードの有効性チェック（カード通し）に見られる、同一商品の機械的購入を見抜く多様性スコア

## 開発環境・使用技術
* **Language:** Python 3.x
* **Libraries:** scikit-learn, pandas, (標準ライブラリ: math, json, csv, collections)
* **Design Pattern:** パイプライン分離（Data Loading ➔ Feature Engineering ➔ Hybrid Detection ➔ Output Generation）
  * ローカルのコエイロインクエンジン（音声合成API）へとパイプし、キャラクターボイスによる自然な音声応答をノーレイテンシーで実現するマルチモーダルアプリを自作。

会話よりも「動くコードと設計」で語るスタンスを大切にしています。
