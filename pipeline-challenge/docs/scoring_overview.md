# スコアリング概要

## 総合スコア：600点満点

提出物は以下のカテゴリで自動評価されます。**各カテゴリの具体的な配点は非公開です。**

## 評価カテゴリ

### 1. 正確性スコア

パイプラインの出力を、**非公開の完全なテストデータセット**（提供されるサンプルデータよりも大規模）と比較して評価します。

- **検知F1スコア** — 異常の検出精度（Precision × Recall の調和平均）

> **アルゴリズムは自由です**: 検知の品質（F1スコア）で評価されます。ルールベース・機械学習・統計的手法など、最適なアプローチを選択してください。

### 2. パフォーマンススコア

実行性能を計測して評価します。

- パイプライン全体の実行時間
- メモリ最大使用量
- CPU利用効率

### 3. スケーラビリティスコア

大規模データセットでパイプラインをテストします。

- 制限時間内にパイプラインが完了するか
- データ量増加時に正確性が維持されるか
- 実行時間のスケーリング特性

### 4. コード品質スコア

自動静的解析による評価です。

- **Dockerfile最適化**: イメージサイズ、レイヤー数、マルチステージビルドの活用
- **リンティング**: 使用言語に適した静的解析（pylint、eslint 等）
- **エラーハンドリング**: 不正データ（NULL値、型不正、重複等）に対するロバストネス
- **Docker Compose構成**: ヘルスチェック、リソース制限、ネットワーク設定

## 重要事項

- すべての採点は**完全自動**で行われ、人による主観的評価は一切含まれません
- 非公開テストデータはサンプルデータよりも**大規模かつ多様**です
- パイプラインは**エッジケース**（NULL値、不正フォーマット、重複データ等）を適切に処理してください
- パフォーマンスは全受験者の結果を基にした**相対評価**です
- **アルゴリズム自由**です。ルールベース・機械学習・統計的手法など最適なアプローチを選択してください
- ラベル付き学習データ（約30%）が提供されていますので、教師あり/半教師あり学習にも活用できます
- 採点は管理者側で実行されます。結果は別途通知されます
